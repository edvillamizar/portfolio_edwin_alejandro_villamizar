## Secciones
- Hero con foto integrada mediante `mask-image` y halo con `radial-gradient`
- Servicios (5 tarjetas)
- Proyectos con enlace a demo y código
- Proceso de trabajo
- Contacto con formulario (Formspree)

## Funcionalidades
- Diseño responsive (breakpoints 980, 768 y 480 px)
- Fondo con degradado y tarjetas con efecto glassmorphism
- Formulario de contacto funcional con Formspree
- Página de privacidad (`privacidad.html`)

## SEO
- Title, meta description, canonical y `theme-color`
- Open Graph y Twitter Card
- Datos estructurados JSON-LD (`ProfessionalService`)
- `robots.txt` y `sitemap.xml`
- Alta en Google Search Console
